# 1. Introduction

This lab focuses on client-side scripting using JavaScript. It covers JavaScript functions, event handling, conditional statements, loops and DOM manipulation to create interactive web pages.

Question Explanations

Question 1: Interactive Text Changer

This question uses JavaScript to change a paragraph when the user clicks the Change Message button.

JavaScript concepts used:

1. getElementById() – Selects HTML elements.

2. function – Creates the changeMessage() function.

3. textContent – Changes the paragraph text.

4. addEventListener() – Detects button clicks.

Expected output: The message changes from "Welcome to my website!" to "Hello there!".

Question 2: Smart Number Validator

This question allows users to enter a number and checks whether it is lower than, higher than or equal to 10.

JavaScript concepts used:

1. trim() – Removes unnecessary spaces.

2. Number() – Converts input into a number.

3. if...else if...else – Checks the input conditions.

4. Number.isFinite() – Checks whether the input is a valid number.

5. textContent – Displays the validation message.

Expected output: The system displays the correct message based on the entered number or displays an error message for invalid input.

Question 3: Dynamic Number Generator

This question generates an ordered list containing numbers from 1 to 5 when the user clicks the Generate button.

JavaScript concepts used:

1. function – Creates the generateNumbers() function.

2. for loop – Repeats the process five times.

3. document.createElement() – Creates new list items.

4. textContent – Sets the text for each list item.

5. appendChild() – Adds list items to the ordered list.

Expected output: The system displays an ordered list from 1 to 5 without duplicate items when the button is clicked repeatedly.
